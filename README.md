**What Todo Now** är en fullstack todo-app byggd med TypeScript, Express, MySQL och Vite.

Projektet började som en klassisk todo-övning men fick snabbt mer personlighet: varje todo får en vibe, en ikon och kan innehålla egna subtasks. Fokus har varit att förstå hur frontend, backend och databas hänger ihop på riktigt — från formulär och fetch-anrop till routes, controllers, MySQL-relationer och renderad UI i browsern.

## Vad appen kan göra

- skapa todos
- välja en vibe för varje todo
- visa vibe-ikoner i listan
- markera todos som done / not done
- ta bort todos
- lägga till subtasks kopplade till en specifik todo
- markera subtasks som done / not done
- ta bort subtasks
- spara data i en MySQL-databas

## Värt att veta innan du klickar runt

Det här är ett skol-/övningsprojekt där frontend och backend ligger i samma repo men körs separat.

- `client/` innehåller frontend byggd med Vite och TypeScript
- `src/` innehåller Express API, routes, controllers och databaskoppling
- databasen körs med MySQL via Aiven
- `.env`-filer och databasuppgifter finns inte i repot

Kort sagt: en todo-app med vibe, byggd för att nöta API:er, TypeScript, Express och databaskoppling.
